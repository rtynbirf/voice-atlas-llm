# RUVSON-ENCODER — свой контент-энкодер с нуля (блюпринт, не реализация)

> Директива владельца: «Whisper и HuBERT обучены на человеческих фонемах — они нам
> что, указ? Авторитет? Эталон? Мы свой можем с нуля сделать!»
> Ответ этой линии: да, механизм воспроизводим. Чужие модели — не эталон, а
> демонстрация механизма. Статус документа: ПРОЕКТ (ни одна строка кода ещё не
> написана; исполняется после закрытия волны «Гибрид» и приборной очереди RSE-2).

## 0. Что наследуем, а что выбрасываем

Сердце HuBERT — НЕ человеческие фонемы, а механизм самообучения с маскированием:
модель угадывает скрытые куски звука, «слова» — кластеры, найденные в данных.
Подай смешанный корпус — кластеры станут трелями соловья, стрекотами цикады,
щелчками сверчка. Это универсальные акустические единицы, найденные машиной
самостоятельно. Фонемы человека — частный случай.

## 1. Корпус (смешанный)

| Источник | Объём | Роль |
|---|---|---|
| Человек: Emilia, LibriTTS-R | ~100k+ часов | база гармонической речи |
| Птицы: Xeno-canto, Macaulay Library | ~1M+ записей | свист/трели до ~9 кГц, диалекты |
| Насекомые/земноводные: выборки BEANS, Macaulay | десятки тысяч часов | негармонические источники (цикада — тимбальные щелчки, F0 отсутствует) |
| Синтетика: свипы, щелчки, шумовые всплески, гармонические ряды | сколько нужно | покрытие пробелов между классами |
| Аугментации: pitch-shift ±2 октавы, ресемплинг, тайм-стретч | — | диапазоны за пределами человеческих |

## 2. Фронтенд

Двухбанковый вход: мел 16 кГц (детали голоса) + мел 44.1 кГц (высокие частоты
птиц); альтернатива — обучаемый фильтрбанк SincNet-стиля (модель сама найдёт
важные полосы) + CQT-ветка для тональных свипов.

## 3. Механизм обучения (HuBERT-механизм, обобщённый)

```text
Итерация 0: кластеризация ВСЕХ кадров корпуса k-means по меловым признакам
            → кластеры = универсальные акустические единицы
Обучение:   маскируем 40–75% кадров → трансформер предсказывает юнит
            маскированного кадра (кросс-энтропия по кластерам)
            + контрастивная голова (истинный латент vs 100 случайных)
            + aux-loss реконструкции спектрограммы
Итерация 1: перекластеризация по ЭМБЕДДИНГАМ модели → переобучение
Итерация 2: повтор → юниты структурны для всех видов
```

## 4. Дизентанглмент (контент не тащит тембр)

- Adversarial-классификатор (градиент-реверс) на контент-потоке: НЕ должен
  угадать ни вид, ни особь. Контент = ЧТО сыграно, не КЕМ и не КЕМ из птиц.
- Timbre shifter (приём Seed-VC, обобщённый): при обучении подменять тембр входа
  собственным RAVE-декодером → модель принудительно учится вынимать структуру
  без тембра источника.
- F0/энергия — отдельным потоком (просодия отдельно от контента); для
  негармонических источников вместо F0 — огибающая энергии + спектральный конверт.

## 5. Сертификация универсальности

- Probing: линейные головки — вид, особь, тип фразы, F0. Контент-слой хорошо
  предсказывает фразу и ПЛОХО — особь; тембр-слой — наоборот. Это математическая
  проверка «родинки» (см. docs/LOZH_SREDNEGO.md): особь не просачивается в контент.
- ABX-дискриминация юнитов внутри вида и между видами.
- SUPERB (человек) + BEANS (животные) одним энкодером = сертификат универсальности.
  AVES — контрольная группа: если наш энкодер бьёт его на BEANS, построен механизм
  лучше, а не копия.

## 6. Вставка в конвейер

Свой энкодер → DiT-генератор (обучение на том же смешанном корпусе) → BigVGAN
44.1 кГц → гейты СУДА (универсальный алгоритм, docs/UNIVERSAL_SOUND_ALGORITHM.md).
Ни одного человечески-предобученного блока в цепочке контента.

## 7. Железо и честная альтернатива

| Путь | Стоимость | Минус |
|---|---|---|
| С нуля, малый энкодер 30–80M | 1×RTX 4090, недели; 8×A100 — дни | нужно больше данных |
| С нуля, большой 300M+ | кластер GPU | бюджет |
| Домотать открытый чекпоинт (AVES) → наш корпус | в 5–10 раз дешевле | наследует перекос базы (у AVES — животный, он честнее человеческого) |

Инженерный вердикт: малый энкодер с нуля на одной карте — уровень дипломной
работы, не Google. Гибрид «AVES + наш корпус» даёт ~80% результата за ~10%
усилий. Оба пути открыты; выбор — за приборной очередью владельца.
