## 2. Что это за система (по факту кода)

Исполнительный контур сценария «голос певца поёт на другом языке» (Дио/Удо/
Шаляпин на уйгурском, вьетнамском, …): разделение (demucs) → строки (SRT или
нарезка по паузам) → посадка перевода (слоги по языкам, тоны вьетнамского) →
гид-вокал (TTS → DTW по энергии → WORLD-ресинтез с F0 оригинала) → смена
тембра (шаблоны Seed-VC/RVC) → сведение (true-peak ≤ −1 дБ) → гейты мелодии
(корреляция F0, RMSE в центах, озвученность) → манифест с хэшами.

Пакет: `vfe/` (11 модулей), CLI `fit|voices|cover|eval`, 41 тест, docs
(TZ/ALGORITHM/COVER_PIPELINE/MERGE_MAP/SOURCES/ROADMAP), реестр компонентов,
бенчмарк-протокол с blind-протоколом прослушивания.

## 3. Соответствие эхо-политике (философия владельца)

- Нет блокирующих consent/license-гейтов: `gates.py` меряет только акустику
  (f0_corr, f0_rmse_cents, voiced_ratio, true_peak). ✔
- Единственный жёсткий технический гейт — неприкосновенность исходника
  (source только читается, sha256 в манифесте, тест подтверждает). ✔
- Честная маркировка: `synthetic_output: true` в манифесте — «подпись автора
  эха», не пропуск и не разрешение. ✔
- Это осознанное решение, задокументированное в `docs/MERGE_MAP.md`: гейты
  согласия/личности/AES/RBAC/C2PA из 0.4/v1.0 «возвращены жёсткими гейтами
  против твоего "без казуистики" → убраны». ✔

**Следствие для voice-atlas-llm:** мои документы v2 (THREAT_MODEL T3, ROADMAP
фаза 4, SPEC §7) писались без этих материалов и содержали блокирующие
consent-гейты — **исправлены в этом же коммите** (см. §6).

## 4. Находки ревизии кода (моя независимая ценность)

**Функциональные (не блокируют, влияют на полноту):**

1. `cli.cmd_cover`: асимметрия строк — при `len(tgt) > len(src)` лишние целевые
   строки используются только до `len(src)` (предупреждение есть в fit_report,
   но в манифест не попадает); при `len(tgt) < len(src)` хвост песни молча
   отбрасывается (`src = src[:len(tgt)]`). Зафиксировать оба случая в манифесте.
2. `fit.fit_report`: при одновременном «too_fast» и «too_long» вердикт — только
   too_fast (приоритет проверки). Документировать или возвращать обе оси.
3. `gates.melody_metrics`: `voiced_ratio` не ограничен сверху — в прогоне e2e
   он равен **1.0197** (результат озвучен «больше оригинала»); верхнего порога
   нет. Добавить `voiced_ratio_max` (калибровать).
4. `guide.transplant`: кадры вне активного спана получают спектр первого кадра
   гида при ap=1 → не тишина, а шум с формантным спектром (тест пропускает
   при RMS < 0.03). Явно обнулять кадры вне `[s0, s1)`.
5. `guide.build_guide`: перекрывающиеся строки складываются аддитивно без
   нормализации — до потолка финального микса возможен промежуточный клип.

**Документированные ограничения (сам сборщик честно пометил):**

6. Флаги внешних команд (demucs/Seed-VC/RVC) — «по памяти, сверять»
   (`registry/GAPS_FROM_CHAT.md`: таблица UNVERIFIED). До реального прогона
   сверить со своим checkout.
7. Пороги гейтов (f0_corr ≥ 0.90 и т.д.) — стартовые, НЕ калиброваны;
   протокол калибровки «оригинал vs второй дубль» описан, не выполнен.
8. Реальные нейросети не запускались ни сборщиком, ни здесь — качество SVC
   не измерено; код проверен на фейковых адаптерах.
9. CI-воркфлоу в пакете нет (тесты есть, автопрогона нет) — при выкладке в
   git добавить Actions на unittest (лёгкие зависимости без torch).
10. `requirements.txt` — без пинов; для воспроизводимости зафиксировать
    (см. требования к пинам в ROADMAP_v2 фаза 0.1 для atlas-репо).

**Экосистемное:**

11. VFE и voice-atlas-llm — две половины одной системы: атлас = знание
    (что и как), VFE = исполнение (звук). ROADMAP_v2 фаза 4 переведена с
    «гипотезы с нуля» на «интеграцию проверенного VFE 0.5.0».
12. `GAPS_FROM_CHAT.md` — лучший антигаллюцинационный артефакт линейки:
    компоненты из ответов разных ИИ с пометками ⚠ на расхождения и статусом
    UNVERIFIED. Принят как образец для будущих ревизий.
