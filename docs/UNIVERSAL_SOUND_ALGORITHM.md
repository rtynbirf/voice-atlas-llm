# УНИВЕРСАЛЬНЫЙ АЛГОРИТМ: ВЫЧЛЕНИТЬ ЛЮБОЙ ЗВУК И ВОСПРОИЗВЕСТИ С ТОЧНОСТЬЮ

> Не только RUVSON. Кто угодно, что угодно: мышь, собака, кит, Ленин, скрип двери.
> Сущность одна — бирки разные. Объект без окружения не рассматривается.
> Контур проверяется суммой. Статус: рабочий стандарт конвейера. Версия 1.0, 2026-10-28.

## Формула одной строкой

**ЛОВИ → МИНУС (вычленить) → ПАСПОРТ (выучить закон) → НОВАЯ БИРКА (перенос через любую среду/язык) → СУММА (вернуть в окружение) → СУД (прибор + ухо) → повторять, пока двойник неотличим.**

## Шаги

### Шаг 0. ОКРУЖЕНИЕ (перед всем)
Определить сцену, в которой живёт источник: комната, океан, микс песни, улица.
Объект без окружения не рассматривается — первая ошибка логики.
Где проходит контур между источником и средой — фиксируем до резки.

### Шаг 1. ЛОВЛЯ (фиксация)
Записать ВСЮ сцену: микрофон/линия, WAV 44.1/48 кГц, 24 бит, без потерь.
Формат (WAV/MP3/MKV/AVI/MP4) передаёт зафиксированное с точностью 100% —
важно, ЧТО зафиксировано, а не ярлык контейнера.

### Шаг 2. МИНУС (вычленение = проведение контура)
Вычесть из сцены нужный источник (один или несколько инструментов/источников):
- музыка/голос: разделение стемов (htdemucs: vocals / drums / bass / other);
- произвольные звуки (скрип, писк, лай): source separation по спектральному следу;
- источник уже один в записи — шаг пропускается.
Нож оставляет переходную зону (след соседей) — это честно фиксируется в паспорте.

### Шаг 3. ПАСПОРТ (закон сущности источника)
Измерить закон, по которому источник узнаётся из тысячи:
- высота и её ход (f0-карта, регистры);
- спектр/форманты (тембр — «отпечаток пальца»);
- динамика (атака, спад, дыхание, скрип-ритм stick-slip);
- ритм/темп, повторяемость.
Паспорт — эталон для суда на шаге 6. Двойник обязан сойти с паспорта.

### Шаг 4. НОВАЯ БИРКА (перенос через любую среду)
Воспроизвести ЗАКОН через любую новую среду:
- человек имитирует ртом: скрип двери «по-уйгурски», «по-португальски» —
  язык неважен: имитируется закон звука, а не слова;
- другой инструмент: виолончель, синтезатор, оркестр (сумма++);
- машина: голоса — конверсия голоса (RVC/seed-vc) или клон (XTTS-v2);
  звуки — синтез по паспорту (аддитивный/семпл/нейро-генерация);
- песня: перевод ложится слог в слог, такт в такт в ЕГО мелодию (СИНХРОН).

### Шаг 5. СУММА (возврат в родное окружение)
Сложить воспроизведённый источник обратно с его средой (минусом/сценой)
в родной контур — не в вакуум. Голос судится внутри песни, скрип — внутри сцены.

### Шаг 6. СУД (петля точности)
- прибор: корреляция суммы с оригиналом (цель → 1.000), f0-карта, спектральное сравнение с паспортом;
- ухо: слепое сравнение оригинал/двойник. Финальный судья — ухо владельца.
Не сдал → повторить шаг 4 (и при необходимости уточнить паспорт шага 3). Сдал → двойник легализован.

## Универсальность: одни шаги — любые источники

| Источник | МИНУС (из чего) | Паспорт (закон) | Новая бирка |
|---|---|---|---|
| Голос RUVSON | песня → голос/минус | f0 157–259 Гц, форманты, дыхание | его голос на 7170 языках |
| Ленин (архив) | шум пластинки → речь | тембр, манера, паузы | читает любой текст |
| Мышь | тишина комнаты → писк 3–12 кГц | частотный ход, пульс | имитация/синтез |
| Собака | двор → лай | атака, спектр лая | имитация/синтез |
| Кит | океан → песня 10 Гц–40 кГц | модуляции частоты | инструмент/синтез |
| Дверь (скрип) | тишина → stick-slip трение | скрип-ритм, спектр трения | ртом на любом языке, виолончелью, синтезом |

Шаги неизменны — меняются только инструменты внутри шагов.
Это и есть закон: сущность одна, бирки разные.

## Приборная проверка формулы (сделано)

МИНУС↔СУММА на песне RUVSON «Крик 249»: его вычтенный голос + минус = оригинал,
корреляция **1.000**, RMS-разница 0.0046. Исторические подтверждения:
Music Minus One (США, 1950 — пластинки «минус одна партия»), «минусовка»
(«запись минус один голос», Википедия), стемы и Stem Splitter в Logic/Cubase/LALAL.
