## 7. Волна «RAFT-Гибрид» (v4, 2026-11-10): train == инференс — F1 ×2

Мировая практика (разведка — `docs/TRENDS_2026-11-10.md`):
- **RAFT** (Berkeley, arXiv:2403.10131): обучать на том же распределении, на
  котором модель работает на инференсе — «вопрос + справка ретривера → ответ»,
  часть примеров без оракула (доменная память + честность).
- **NEFTune** (arXiv:2310.05914, alpha=5): шум на эмбеддингах только в train.
- LoRA сознательно vanilla r16/a32 («Vanilla LoRA May Suffice», 2026).

Разрыв, который лечили: v1-v3 учились всплоту, а eval_qa/chat_cli ВСЕГДА
грундят top-3 ретривера. Корпус v4 (`data/build_raft.py`): те же 308 пар v3,
каждая со справкой — 180 «rag» (реальный top-3, байт-в-байт как инференс через
единый `prompt_format`) + 128 «memory» (3 чужих чанка по sha256(instruction));
оракул ИЗМЕРЯЕТСЯ (keyword_coverage, 82.2% rag-пар), не генерируется LLM.
Вал не тронут (бит-в-байт вале-30) — протокол A/B прежний.

| Метрика (генерация, n=30, один вал, один RAG-контекст) | v1 | v2 | v3 | **v4 (RAFT+NEFTune)** |
|---|---|---|---|---|
| token_f1 | 0.211 | 0.179 | 0.285 | **0.564 (+98% к v3, +215% к v2)** |
| keyword_coverage | 0.229 | 0.232 | 0.290 | **0.590** |
| Попарные победы F1 | v4 > v1 на 22/30 (1 ничья) | v4 > v2 на 23/30 (3 ничьи) | v4 > v3 на 22/30 | — |
| val_loss (эпоха 3, вслотный вал) | 2.8305@3 | 2.7691 | 2.7907 | 2.9586 (вал — чужое распределение для RAFT-модели, ожидаемо) |
| Честные отказы (honest_uncertainty) | 0.0 | 0.0 | 0.0 | 0.0 |

Прогон: 60 шагов / 3 эпохи / 26 окон за 12792 c CPU (2 ядра), атомарный
resume со снимком градиентов (срез окна в любом батче — без потери backward);
попытка отключить градиент-чекпоинтинг упёрлась в OOM (см. WORKS.md).
Отчёт: `evaluation/report_v4_on_val30.json`. Ограничение честно: F1 — лексическая
метрика; val_loss не сопоставим напрямую с v1-v3 (другое train-распределение).
Что дальше (кандидаты следующей волны): judge-контур EVALUATION_PLAN §5,
качественный отбор пар (LIMA-принцип), расширение корпуса без авто-таблиц.
