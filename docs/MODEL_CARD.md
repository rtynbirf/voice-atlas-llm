корпусу атласа клонирования голоса.

| Поле | Значение |
|---|---|

## 4. Предназначение

- ✅ Ответы по терминологии/технологиям/порогам/законам атласа с RAG-источниками.
- ✅ Демонстрация полного воспроизводимого пайплайна «корпус → датасет → LoRA → гейт».
- ❌ Не предназначена: факты вне корпуса (галлюцинирует), медицинские/юридические/
  финансовые заключения, автономные действия, продакшн-сервис без гейта.
- ❌ Не синтезирует и не клонирует голос — текстовый эксперт по теме (SYNTHESIS §2 #1).

## 5. Ограничения и честные предупреждения

1. 0.5B: слабое рассуждение, повторы, выдуманные ссылки на длинных цепочках —
   эмпирически подтверждено отчётом eval.
2. Знания ограничены корпусом на 2026-10; мир технологий голоса меняется быстрее
   атласа — ответы «по состоянию корпуса».
3. n=9 — недостаточно для статистических выводов; golden set 100+ — в плане.
4. Число «сходство 75–85%» из README — ожидание из лестницы главы 10 атласа,
   НЕ калиброванный результат этой модели.
5. Метрики порогов атласа (SIM/WER/UTMOS) к этой текстовой модели неприменимы.
