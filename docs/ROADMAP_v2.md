# Дорожная карта v2.0

**Дата:** 2026-10-27 · **Статус v1:** `docs/roadmap.md` (v0.1–v0.4, актуален)
**Отличие v2:** фазы переупорядочены по результатам антигаллюцинационного аудита
(`docs/audit/SYNTHESIS.md`): сначала доверие к измерениям (CI, воспроизводимость,
антиутечка, абляция), потом вкус (DPO), потом масштаб (7–8B), голос — последним.

Каждая фаза ссылается на источник требования: [С#n] — верифицированные коллеги
из SYNTHESIS, [Атлас гл.n] — главы корпуса, [Собств.] — собственные находки аудита.

## Фаза 4 · Голосовой контур = интеграция VFE 0.5.0 (после 1–3)

**База готова:** исполняемый контур «голос певца поёт на другом языке» уже
существует как Voice Fidelity Engine 0.5.0 (41/41 тестов воспроизведены
независимо — см. `docs/audit/VFE_050_REVIEW.md`). Писать с нуля не нужно.
Политика — эхо (T3 THREAT_MODEL): без разрешительных процедур; жёсткий гейт
один — неприкосновенность исходника; честная маркировка синтетики.

**Цель фазы — голос RUVSON (постановка владельца, 2026-10-27).** Миссия —
наследие: зафиксировать голос человека, говорящего сквозь RUVSON, чтобы голос
и глубина смысла его текстов пережили создателя — для тех, кто придёт после
нас (устав: `docs/MISSION.md`). Исходник —
Drive-папка «RUVSON - Videos» (50 файлов: 48 mp4 + 2 mp3, ~3.6 ГБ; нумерация
треков 01–50, №21 отсутствует, трек 01 в двух форматах). Контур фазы:
mp4 → извлечение аудиодорожек (ffmpeg) → вокал-сепарация → VFE 0.5.0 →
голосовая модель RUVSON. Промеренное семя и план инжеста —
`docs/RUVSON_VOICE_PLAN.md`.
