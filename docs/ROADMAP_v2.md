# Дорожная карта v2.0

**Дата:** 2026-10-27 · **Статус v1:** `docs/roadmap.md` (v0.1–v0.4, актуален)
**Отличие v2:** фазы переупорядочены по результатам антигаллюцинационного аудита
(`docs/audit/SYNTHESIS.md`): сначала доверие к измерениям (CI, воспроизводимость,
антиутечка, абляция), потом вкус (DPO), потом масштаб (7–8B), голос — последним.

Каждая фаза ссылается на источник требования: [С#n] — верифицированные коллеги
из SYNTHESIS, [Атлас гл.n] — главы корпуса, [Собств.] — собственные находки аудита.
