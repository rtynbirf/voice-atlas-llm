## 2. Сборка и валидация

`python data/build_dataset.py [--seed 42] [--val-frac 0.06]`:
непустые поля, минимальная длина ответа, наличие кириллицы, дедупликация по
instruction, затем shuffle + сплит. Всё детерминировано seed'ом.

**Известный дефект методологии (аудит SYNTHESIS §4.3):** сплит — глобальный
shuffle без группировки по (глава, термин): близнецы могут пересечь границу
train/val. Исправление — фаза 0.4 роадмапа v2 (сплит по группам + отчёт о близнецах).

**Известная хрупкость сборщика:** глоссарий извлекается regex'ом по строгому
формату таблицы; отклонения форматирования тихо теряют пары (коллега #10,
верифицировано). План — фаза 1.4.

## 3. Системный промпт

`data/curated/system_prompt.txt` — идентичность модели, четыре слоя
дизентанглмента (TTS/VC/SVC/SVS), правило «копия — наследник, а не двойник»,
законы атласа, включая закон 7 (согласие носителя). Входит в prompt каждой пары
(205 токенов — учтено в измерении длин).

## 5. Персональные данные и голоса

- В корпусе и датасете **нет** персональных аудиозаписей, имён частных лиц,
  голосовых отпечатков. Тексты — технические описания технологий.
- Закон 7 (согласие носителя) — знание корпуса: модель знает его как факт
  атласа и отвечает по нему, но **движок не превращает его в разрешительную
  процедуру** (эхо-политика владельца: T3 THREAT_MODEL; VFE 0.5.0 — consent-
  гейты информационные, единственный жёсткий гейт — source_immutable,
  синтетика маркируется манифестом).
- Голосовые данные появятся только в фазе 4 (интеграция VFE 0.5.0 — см.
  docs/audit/VFE_050_REVIEW.md); операции с аудио фиксируются манифестами с хэшами.
- Удаление: датасет и корпус удаляются вместе с репозиторием/веткой; git-история
  сохраняет все версии до форс-удаления.

## 6. Ограничения состава

1. Корпус — снимок знаний на 2026-10; части «2026-тренды» устаревают быстрее глав-основ.
2. Глоссарий покрывает 24 термина из оглавления гл. 18, не весь словарь домена.
3. Кураторские пары отражают структуру атласа; вопросно-ответное разнообразие
   ограничено (пара «вопрос-вариант» может выглядеть близко — см. §2 дефект сплита).
4. Датасет не содержит диалоговых контекстов (одноходовые QA) — диалог — фаза
   расширения до 600+ пар (роадмап v1 v0.3, поглощён фазой 2 v2).
