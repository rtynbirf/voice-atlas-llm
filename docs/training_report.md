# Отчёт об обучении Атлас-LLM

Все цифры ниже — реальные логи прогонов этого репозитория, без прикрас
(дисциплина главы 11 и главы 20 атласа: отчёт ≠ обещание).

## Прогон 1 — smoke пайплайна (tiny-gpt2, CPU)

- Конфиг: `training/configs/smoke-tiny.yaml` (sshleifer/tiny-gpt2, 0.1M параметров)
- Задача: проверить код обучения, а не качество.
- Результат: 39 шагов, 43 с, лосс ≈ 10.82 (плоский — ожидаемо:
  у модели hidden=2, LoRA 0.06% параметров, 1 эпоха).
- Вывод: **пайплайн исправен** — датасет, маска лосса, оптимизатор,
  сохранение адаптера и отчёта работают end-to-end.

## Прогон 2 — proof на реальной модели (Qwen2.5-0.5B-Instruct, CPU)

- Конфиг: `training/configs/cpu-proof-qwen.yaml`, `--limit 4`
- 4 шага, 12 с, лосс 3.72 → 3.53, val 3.61.
- Вывод: реальная модель грузится, градиенты текут, адаптер сохраняется.

## Прогон 3 — demo-обучение (Qwen2.5-0.5B-Instruct, CPU) — артефакт в репо

- Конфиг: `training/configs/cpu-demo-qwen.yaml`, `--limit 50`
- Условия: bf16-веса на CPU (4 ГБ RAM!), max_len 448, batch 1, grad_accum 2,
  LoRA r=16 на всех проекциях → 8.80M обучаемых параметров (1.75%).
- Результат: 25 оптимизаторных шагов за 173 с.
  - train loss: 3.88 → 3.13 → 2.98 (шумно по микробатчам, тренд вниз)
  - val_loss: 3.26
- Проверка генерации (chat_cli + адаптер + RAG): модель выдаёт связный
  русский текст по формату «Вопрос/Ответ», но семантика после 25 шагов
  слабая — это ДЕМО-адаптер, а не готовая модель.
- Инженерные находки (задокументированы для будущих прогонов):
  - Кириллица в gpt2-BPE раздувает текст до 3–4 токенов/символ:
    в smoke-конфиге max_len должен покрывать ответ целиком;
    в тренере реализована обрезка промпта слева с сохранением ответа.
  - На 4 ГБ RAM batch_size ≥ 2 при seq 448–512 убивает процесс (OOM,
    exit 137): CPU-прогоны — batch 1 + bf16-веса.
  - `huggingface_hub`-загрузка весов может залипать на лимитах:
    прямое скачивание через curl в `models/_base/` решает это.

## Оценка RAG (без генерации)

`python evaluation/eval_qa.py --retrieval-only --max-samples 9`:
mean_rag_coverage = 0.49 по ключевым словам эталона в топ-1 чанке.
TF-IDF по char_wb 3–5 граммам находит релевантную главу устойчиво;
покрытие «всего ответа» одним чанком естественно частичное.

## Как запустить полное обучение

```bash
# RTX 3060 12 ГБ или Colab T4
pip install -r requirements.txt -r requirements-ml.txt
python data/build_dataset.py
python training/train_lora.py --config training/configs/qwen2.5-0.5b-ru.yaml
python evaluation/eval_qa.py --adapter models/atlas-qwen-0.5b --max-samples 9
```
