# voices/ — реестр голосов с sha256-пломбами (П56, issue #7)

Атлас голосов: что заявлено — то запломбировано; что запломбировано — то
проверяется машиной при каждом прогоне.

## Состав

| Файл | Роль |
|---|---|
| `manifest.json` | реестр: голос → язык, лицензия, источник, sha256-пломба |
| `build_registry.py` | детерминированный сборщик реестра из `data/ruvson/MANIFEST.jsonl` (50 записей корпуса) + голосовых GitHub-релизов |
| `lint.py` | линт: схема, корпус 50/50 бит-в-бит, локальные пломбы, сироты, фантомы, кросс-чек хешей WORKS.md; `--selftest` — негатив |
| `seal.py` | пломбовщик: `seal` (live-sha256 → запись), `verify` (файл vs пломба), `selftest` (подмена байта = красный) |
| `audio/` | локальные семплы (конвенция; кладёшь файл → `python3 voices/seal.py seal voices/audio/<файл>`) |

## Машинная приёмка П56

```bash
python3 voices/build_registry.py --check   # двойная сборка байт-идентична
python3 voices/lint.py                     # VOICES_LINT=PASS
python3 voices/lint.py --selftest          # испорченная пломба/сирота/фантом = красный
python3 voices/seal.py selftest            # подмена байта = красный
```

Всё std-only Python, CI-шаг «П56 — реестр голосов» гоняет это на каждом пушe.

## Честные границы (2026-11-09, волна ×4)
