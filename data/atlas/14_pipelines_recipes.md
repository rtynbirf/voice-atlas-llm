# Глава 14. Пять готовых пайплайнов-рецептов

Ниже — пять собранных конвейеров под типовые сценарии 2026 года. Для каждого указаны стек, объём данных, железо и время до первого результата. Все рецепты начинаются с этапа 0 (согласие носителя голоса) и заканчиваются гейтом качества (глава 11) — эти скобки опущены в описаниях ради краткости, но их исполнение обязательно.

## Рецепт 1. AI-кавер: «поёт как он» (SVC, ноль обучения)

| Компонент | Выбор |
|---|---|
| Стек | UVR5 (Mel-Band RoFormer) → Seed-VC (модель SVC 44.1 кГц, f0-condition=True, steps 30–50) → мастеринг |
| Данные | Референс голоса 10–30 с; исходная песня |
| Железо | RTX 3060 12 ГБ / Colab T4 |
| Время | Первый результат — 15–30 минут; тонкая подгонка полутона — ещё полчаса |

Ключевые настройки: auto-f0-adjust выключен (сохраняем тональность песни), semi-tone-shift подбирается под комфортный диапазон целевого голоса, длинные треки рендерятся чанками с кроссфейдами автоматически. Для постоянного персонажа переключитесь на RVC/Applio: файнтюн на 10–30 минутах вокала даст стабильность и реалтайм.

## Рецепт 2. Персональный TTS: «говорит как я» (файнтюн)

| Компонент | Выбор |
|---|---|
| Стек | Silero VAD + WhisperX → GPT-SoVITS v2 (файнтюн) либо CosyVoice 3 / Qwen3-TTS (zero-shot + LoRA) → гейт SIM/WER |
| Данные | 10–30 минут чистой речи (zero-shot: 3–10 с) |
| Железо | RTX 3060 12 ГБ (файнтюн 30–60 мин) / T4 в Colab |
| Время | Zero-shot — минуты; файнтюн — один вечер |

Русский язык: GPT-SoVITS v2+ имеет встроенную поддержку, для CosyVoice/Qwen3-TTS русский поддержан из коробки — но проверьте произношение чисел, дат и латинских вкраплений на своём материале. Для книг и подкастов добавьте реставрационный слой и генерацию по абзацам с единым seed.

## Рецепт 3. Реалтайм-перевоплощение (стриминг, звонки)

| Компонент | Выбор |
|---|---|
| Стек | w-okada voice-changer (VC Client) + RVC-модель (индекс) либо Seed-VC realtime (v1 tiny, ~300 мс) |
| Данные | Персональная RVC-модель: 10–30 мин |
| Железо | RTX 3060+; задержка 80–300 мс в зависимости от модели и размера чанка |
| Время | 1–2 часа на настройку буферов и latency |

Компромисс реалтайма: размер чанка определяет задержку против качества (маленький чанк — «зубчатость»); HIFT/istft-вокодеры быстрее BigVGAN. Для игр и стримов RVC остаётся стандартом, для мультиязычных звонков — Seed-VC realtime.

## Рецепт 4. Текст → поёт как ты (SVS)

| Компонент | Выбор |
|---|---|
| Стек | Запись 30–60 мин пения → MFA-разметка → голосбанк DiffSinger → OpenUtau (ноты + текст) → рендер → опционально полировка SVC |
| Данные | 30–60 минут чистого вокала с нотной разметкой |
| Железо | RTX 3060+ (обучение голосбанка 4–12 ч) |
| Время | Первый голосбанк — 2–3 дня вместе с разметкой |

Мелодию для готовой песни достаёт basic-pitch (аудио → MIDI) с последующей правкой в редакторе. Для коммерческих требований ближе ACE Studio / Synthesizer V — качество рендера выше, но тембр «твоего голоса» потребует импорта или лицензирования.

## Рецепт 5. Клон стиля письма (LLM-персона)

| Компонент | Выбор |
|---|---|
| Стек | Корпус → очистка/дедуп → LoRA (Unsloth/PEFT на Qwen/Llama) → DPO на парах «оригинал/карикатура» → RAG подлинных фраз → гейт стилевых метрик |
| Данные | От 50 качественных фрагментов; комфортно — 1–10 МБ чистого текста |
| Железо | QLoRA 7–8B: RTX 3060 12 ГБ; 70B+: 2×24 ГБ или облако |
| Время | Промпт-клон — час; LoRA+DPO — один день |

Гейт для текста: близость распределения лексики, стилевой классификатор «оригинал vs копия», слепое чтение 10+ экспертами. Обязательный предохранитель — отдельная система-промпт с границами тем и отказом от имитации человека в деликатных контекстах.
